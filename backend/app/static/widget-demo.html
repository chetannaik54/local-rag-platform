Chat widget demo

Paste an embed key (Admin › Website embed) to try the chat on this page. The page's origin () must be in that key's allowed websites.

Add it to your site

<script src="https://YOUR-SERVER/widget.js" data-key="pk_..." async></script>

Inline instead of a floating bubble: add data-container="#chat" and a <div id="chat" style="height:520px">.
